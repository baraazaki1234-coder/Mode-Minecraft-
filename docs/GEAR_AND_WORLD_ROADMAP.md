# RIFTBOUND — Gear, regions, structures, and worlds roadmap

## Implemented gear tranche 0.7.0
- Emberguard armor: four independently wearable pieces, crafted from Embersteel Ingots.
- Riftbreaker: a heavier axe with higher attack damage and lower durability than the Riftblade.
- Current item icons reuse vanilla iron gear textures as temporary placeholders. Original artwork is not complete.
- This tranche is gear progression only; it does not claim to add custom regions, structures, or dimensions.

## World progression blueprint
The world must be built as connected expedition loops, not as a random list of biomes.

### First frontier — Emberfall Reach
- Surface region with exposed Embersteel deposits and ruined watch posts.
- Guardian role: Ironback patrols the approach; a named elite guardian belongs at the ruin.
- Reward: Embersteel supply and the first forge pattern.

### Second frontier — The Shattered Galleries
- Deep underground network with narrow routes, resource chambers, and sealed vaults.
- Guardian role: Skitter packs defend passages; Hollowmaw guards the deepest vault.
- Reward: Rift Shards and components for advanced weapons.

### Third frontier — The Crown Scar
- Rare high-altitude hostile zone built around a colossal landmark.
- Guardian role: Rift Colossus is the regional boss, not a routine spawn.
- Reward: a world-key component for a later dimension gate.

### Future dimension — The Veil
- Unlock only after the player team earns and crafts the gate key.
- Distinct environment, resources, hostile ecology, and structures must ship together.
- No dimension should exist only as a recolored copy of the Overworld.

## Structure rules
- Every structure has a readable silhouette, a reason to explore it, and a guardian encounter.
- Guardians protect a location or reward; they are not simply extra random mobs.
- Loot must be authored and balanced against the gear tier it unlocks.
- Structures and dimension gates are not marked implemented until actual Bedrock generation assets and runtime tests exist.

## Next implementation stages
1. Add a structure-and-guardian encounter prototype using supported Bedrock structure/feature files.
2. Add a second weapon archetype and a ranged weapon only after their projectile behavior is schema-validated.
3. Add a second armor tier whose crafting chain depends on a guarded structure reward.
4. Implement a region unlock and dimension gate after the first structure loop is verified in-game.
