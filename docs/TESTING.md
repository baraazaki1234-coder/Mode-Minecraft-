# Test checklist

- [ ] Both packs import without manifest errors.
- [ ] Behavior and resource pack dependency UUIDs match.
- [ ] Custom items appear with their intended icons and names.
- [ ] Recipes work in survival.
- [ ] Four players can join the same world.
- [ ] PvP and team rules behave as intended.
- [ ] Death does not wipe long-term progression.
- [ ] No repeated script errors or noticeable mobile performance regression.
- [ ] Test on the exact target Minecraft version before release.
